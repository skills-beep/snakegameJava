Snake Game - Java Swing
A classic 2D Snake Game built using Java Swing. Control the snake to eat food, grow longer, and increase your score. Avoid colliding with the walls or the snake’s body. The game features dynamic difficulty, pause, restart, and high score tracking.

Features:
Real-time controls using arrow keys.

Pause/Resume functionality with the 'P' key.

Restart the game using the 'Enter' key.

Increasing difficulty as the score grows.

High score tracking saved to a text file.

Visual effects with grass patches and smooth animations.

Requirements:
Java 8 or higher.
